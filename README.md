# 北海道・小樽全區沉浸探索

從小樽運河出發，探索小樽市的港灣、老街、山上展望台、溫泉及西海岸。網站含六個導覽區及二十二個景點，支援繁體中文、日本語與 English。

| 導覽區 | 景點 | 路線 |
| --- | --- | --- |
| 運河 | 淺草橋、中央橋、舊小樽倉庫、北運河 | 步行示意，約 742 公尺 |
| 堺町・南小樽 | 舊三井銀行小樽支行、北一硝子三號館、小樽音樂盒堂本館 | 步行示意 |
| 祝津 | 舊茨木家漁工宿舍、小樽水族館、小樽市鯡魚御殿、祝津全景展望台 | 空中巡覽 |
| 市街・天狗山 | JR 小樽站、舊小樽區公會堂、天狗山展望台 | 空中巡覽 |
| 朝里・錢函 | 朝里川溫泉、朝里大壩、張碓・惠比須島、錢函站 | 空中巡覽 |
| 西海岸 | 奧塔莫伊海岸、鹽谷海岸、忍路灣、蘭島海水浴場 | 空中巡覽 |

## 快速啟動

Windows 使用者可完整解壓縮專案，再雙擊 `啟動網站.cmd`。也可用 Node.js 22 或更新版本，在專案資料夾執行下列指令。

```bash
npm run check
npm start
```

開啟 [本機預覽](http://127.0.0.1:5173/)。使用網站期間請保留服務。完整操作見 [安裝與 GitHub Pages 部署](INSTALL.md)。

## 操作

| 功能 | 操作方式 |
| --- | --- |
| 全市地圖及區域 | 點「3D 地圖」查看六區，選擇區域標記查看景點。頂部區域按鈕也可篩選，點「全區」返回總覽。 |
| 移動及飛行 | 地圖用滑鼠拖曳旋轉、滾輪縮放及右鍵拖曳平移。手機使用單指旋轉、雙指縮放和平移。「自由飛行」以 W / A / S / D 或方向鍵移動，E 上升、Q 下降，Esc 離開；手機可長按方向及升降鍵。 |
| 街景及介紹 | 點分區內的地圖標記、景點卡片或景點切換鍵。照片可放大和平移，有多張照片時可用計數按鈕切換。資訊欄連至各景點的資料來源。 |
| 區域路線 | 點頁首的導覽按鈕，沿目前景點所在區域逐站移動。可暫停、繼續和停止。空中巡覽使用景點連線示意。啟用「減少動態效果」時，採逐站切換。 |
| 語音與語言 | 「語音導覽」透過裝置朗讀當前語言的介紹。缺少對應語音時顯示提示，仍可閱讀文字。 |
| 夜景及全螢幕 | 月亮按鈕切換色調，淺草橋可顯示獨立夜景照片；全螢幕按鈕可放大探索區。裝置未提供原生全螢幕時，使用頁面內滿版模式。 |

全區地圖繪製 OpenStreetMap 海岸線、主要道路、水域與綠地。代表景點周邊提供建築模型，優先採用已登錄的建築高度及樓層，其餘估算。未提供 WebGL 2 的瀏覽器會切換至平面地圖。街景為可放大和平移的實地照片。

## 維護

- 景點、照片與分區設定都在 `data/places.json`。座標採 `[經度, 緯度]`。每區的 `stops` 定義導覽順序，`segments` 每段須與相鄰兩站的座標相接。
- 新增照片時，將 WebP 和可讀的縮圖存入 `assets/photos/`，填寫作者、原作、授權及三語替代文字。完成後執行 `npm run check`。
- 圖資及圖片隨網站託管。執行時無須付費 API、金鑰、套件安裝或後端。自撰程式含繁體中文註解。作者、資料版本與地圖來源詳見 [資料來源與授權](CREDITS.md)。
